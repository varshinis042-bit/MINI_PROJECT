## Project Overview

Cardiovascular diseases (CVDs) remain the leading cause of mortality globally, disproportionately affecting South Asian populations due to genetic susceptibility, atherogenic dyslipidemia, and distinctive dietary patterns (high sodium, refined carbohydrates, and saturated fats). 

This project delivers an **end-to-end clinical AI application** that:
1. Calculates a **calibrated 10-year cardiovascular risk probability** using a Stacking Ensemble of 6 distinct ML architectures.
2. Explains individual model decisions using **SHAP (SHapley Additive exPlanations)** to establish clinical transparency.
3. Quantifies **Model Uncertainty** to prevent false clinical overconfidence.
4. Audits **Demographic Fairness** across biological sex and age brackets.
5. Formulates **Personalized Indian Diet Plans** drawing from a verified database of 50+ regional dishes (DASH/Indian Heart guidelines).
6. Analyzes daily self-reported meals dynamically with an automated **0-100 Diet Health Score**.
7. Transparently computes an overall **Lifestyle Risk Score** across 6 behavioral pillars.
8. Powers an interactive **What-If Lifestyle Simulator** to visualize hypothetical biomarker reductions.
9. Provides a **Conservative Exercise Protocol** with red-flag contraindication filters.
10. Enforces an **Emergency Symptom Triage** safety module with direct-dispatch hotline integration.

## Key Innovations

| # | Innovation | Technical Description |
|---|---|---|
| **1** | **Stacking Ensemble Classifier** | Combines Logistic Regression, Random Forest, XGBoost, LightGBM, SVM, and Multi-Layer Perceptron (MLP) with a meta-logistic regression trained on out-of-fold cross-validated probabilities. |
| **2** | **Explainable AI (SHAP)** | Implements `shap.TreeExplainer` to calculate local Shapley attribution values for every incoming patient, mapping raw vectors to positive (risk-elevating) and negative (protective) drivers. |
| **3** | **Uncertainty-Aware Inference** | Quantifies prediction variance and entropy across base models in the ensemble, classifying confidence into High, Moderate, or Low with clinician notes. |
| **4** | **Demographic Fairness Auditing** | Evaluates Recall, Precision, False Positive Rate (FPR), and Disparate Impact across biological sex (`male` vs `female`) and age cohorts (`<45`, `45-60`, `>60`). |
| **5** | **Indian Food Recommendation Database** | Database of 50+ authentic North/South Indian items (Idli, Sambar, Upma, Pongal, Millets, Moong Dal Khichdi, Chana Masala, Fish Curry, Chaas, Makhana) with verified macronutrients, sodium, fiber, and glycemic indices. |
| **6** | **Dynamic Meal Analysis Engine** | Parses daily logged meals, tallies aggregate sodium, saturated fat, fiber, protein, and calories, and computes an automated 0-100 Diet Score with cultural substitutions. |
| **7** | **Transparent Lifestyle Scoring** | Mathematically defined composite formula: `Composite = 0.25*Diet + 0.20*Activity + 0.15*Sleep + 0.20*Smoking + 0.10*Stress + 0.10*BMI`. |
| **8** | **Counterfactual What-If Simulator** | Real-time slider simulation allowing users to adjust modifiable clinical targets (BP, Cholesterol, Glucose, Weight, Smoking) and view instant model re-predictions and delta ($\Delta\%$). |
| **9** | **Conservative Exercise Engine** | Safety-first activity recommendations with automatic contraindication for severe hypertension (SBP $\ge 180$ or DBP $\ge 110$). |
| **10** | **Dual-Mode Database Abstraction** | Seamlessly connects to MongoDB when present, and automatically falls back to an embedded persistent SQLite/JSON store for zero-setup local execution. |

## Dataset & Clinical Features

The system trains on an epidemiologically grounded cardiovascular cohort calibrated according to the **Framingham Heart Study** and **ACC/AHA Guideline Equations**.

- **Sample Size**: 2,500 patient records
- **Split**: 80% Training (2,000) / 20% Hold-Out Testing (500)
- **Prevalence**: ~32% Elevated Cardiovascular Risk
- **Clinical & Lifestyle Features**:
  1. `age`: Patient age in years (20-80)
  2. `sex`: Biological sex (`male`, `female`)
  3. `height_cm` & `weight_kg`: Anthropometrics
  4. `bmi`: Body Mass Index ($kg/m^2$)
  5. `systolic_bp` & `diastolic_bp`: Hemodynamics in mmHg
  6. `cholesterol`: Total serum cholesterol in mg/dL
  7. `blood_glucose`: Fasting glucose in mg/dL
  8. `resting_hr`: Resting heart rate in beats per minute
  9. `smoking_status`: `never`, `former`, `current`
  10. `diabetes_status`: `no`, `pre_diabetes`, `type1`, `type2`
  11. `family_history`: Binary indicator of premature family CVD
  12. `physical_activity`: `sedentary`, `light`, `moderate`, `active`, `very_active`
  13. `sleep_duration`: Average daily sleep in hours
  14. `stress_level`: Self-reported stress (1 to 5)
  15. `alcohol_status`: `none`, `occasional`, `moderate`, `heavy`
- **Engineered Physiology Features**:
  - `pulse_pressure`: $PP = SBP - DBP$ (Arterial stiffness)
  - `mean_arterial_pressure`: $MAP = \frac{2 \times DBP + SBP}{3}$
  - `chol_glucose_index`: Combined cardiometabolic risk factor
  - `high_bp_stage2`: Binary threshold ($SBP \ge 140$ or $DBP \ge 90$)
  - `obesity_flag`: Binary indicator ($BMI \ge 30$)

## Machine Learning Pipeline

### Algorithms Evaluated
1. **Logistic Regression (L2 Regularized)**
2. **Random Forest Classifier**
3. **XGBoost Classifier (Optuna Tuned)**
4. **LightGBM Classifier**
5. **Support Vector Machine (RBF Kernel with calibrated probabilities)**
6. **Multi-Layer Perceptron (Neural Network)**
7. **Stacking Ensemble Classifier (Meta Logistic Regression)**

## Explainable AI (SHAP)

To prevent the AI from functioning as a "black box," every prediction is passed through a SHAP `TreeExplainer`:
- Calculates the expected **base value** (average cohort risk).
- Maps the exact directional push of each biomarker:
  - **Risk Elevators (Red)**: Factors that push predicted risk higher (e.g. Systolic BP 155 mmHg $\rightarrow +0.18$).
  - **Protective Factors (Green)**: Favorable habits that reduce risk (e.g. Non-Smoker status $\rightarrow -0.12$).
- Outputs a natural language clinical explanation summarizing the primary physiological drivers.

## Installation & Setup

### Prerequisites
- **Python**: Version 3.10 (recommended for pre-compiled wheel compatibility)
- **Node.js**: Version 18+ or 20+
- **MongoDB** (Optional; automatic fallback to SQLite is built in)

### Step 1: Clone Repository
```bash
git clone <repo-url>
cd cardiovascular-risk-ai
```

### Step 2: Backend Setup
```bash
cd backend

# Create Python 3.10 virtual environment
py -3.10 -m venv venv

# Activate virtual environment (Windows)
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
pip install email-validator
```

### Step 3: Train the ML Pipeline
Execute the standalone ML training script:
```bash
python -m app.ml.train
```
This script will:
1. Generate and validate the research dataset.
2. Train all 6 base models with Optuna hyperparameter tuning.
3. Train the Stacking Ensemble meta-learner.
4. Fit the SHAP TreeExplainer.
5. Conduct demographic fairness evaluations.
6. Serialize models to `backend/models/saved_models/`.

### Step 4: Start Backend API Server
```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
- API Docs: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- Health Check: [http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health)

### Step 5: Frontend Setup
In a separate terminal:
```bash
cd frontend

# Install npm dependencies
npm install

# Start Vite development server
npm run dev
```
Open your browser at: **[http://127.0.0.1:5173](http://127.0.0.1:5173)**

## Limitations & Future Roadmap

### Academic Limitations
1. **Cohort Homogeneity**: Models were trained on public and synthesized epidemiological distributions. Clinical validation on diverse real-world hospital EHR systems is required prior to hospital deployment.
2. **Observational Counterfactuals**: The What-If Simulator projects statistical associations from observational data; it does not model complex pharmacological pharmacokinetic interactions.
3. **Self-Reported Dietary Precision**: Dynamic meal logging relies on approximate serving estimates and standard Indian food composition tables.

### Future Enhancements
- Integration of continuous telemetry data from wearable devices (Apple Watch, Fitbit, smart ECG monitors).
- Computer Vision for automatic Indian meal recognition from camera photos.
- LLM-assisted conversational dietary coaching utilizing local quantized models (e.g. Llama-3 / Gemma).
